# skill-suggester
Always-on proactive skill advisor for Antigravity, Claude Code, and AI coding agents. Automatically analyzes tasks and suggests the best engineering skill (TDD, Ponytail, Diagnosing-bugs, Blueprint, Code-Review).
antigravity, ai-agents, agent-skills, claude-code, developer-tools, tdd, debugging, code-review, always-on, prompt-engineering
What is skill-suggester?

skill-suggester is an intelligent, always-on routing skill designed for Google Antigravity, Claude Code, and markdown-based AI agent harnesses.

Most AI coding assistants default to generic "vibe coding"—guessing an implementation without adhering to formal engineering disciplines. skill-suggester solves this by continuously monitoring user tasks and automatically recommending the optimal specialized skill from a curated catalog of 300+ practices.

How It Operates:
Silent Intent Analysis: Detects the domain of your prompt (e.g., bug diagnosis, new feature planning, refactoring, code bloat, diff review).
Catalog Mapping: Cross-references your task with specialized skills:
Bugs & Regressions 
→
→ diagnosing-bugs (6-phase feedback loop)
Writing Code Test-First 
→
→ tdd / tdd-workflow (Red-Green-Refactor)
Over-engineering & Bloat 
→
→ ponytail (Lazy senior developer / YAGNI)
Multi-PR Architecture 
→
→ blueprint (Cold-start construction plans)
Code Diffs & PRs 
→
→ code-review (Two-axis Standards vs. Spec review)
Module Depth & Architecture 
→
→ improve-codebase-architecture (Visual before/after Mermaid diagrams)
Design Clarification 
→
→ grill-me (Depth-first requirement stress-testing)
Proactive Callout: Injects a concise 1–2 line suggestion badge into the response showing what skill to use, why it was chosen, and how to trigger it.
